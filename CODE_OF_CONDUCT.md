# Code of Conduct

## Our standard

Better Codex is a public project for people with different backgrounds, experience levels, languages, and opinions. Participants are expected to:

- Be respectful and specific when discussing code, product decisions, and user reports.
- Assume good intent while addressing the technical issue directly.
- Welcome questions from people who are new to Codex, GitHub, or open-source development.
- Accept constructive feedback and revise claims when new evidence appears.
- Protect private task content, conversation transcripts, credentials, and personal data.

Unacceptable behavior includes harassment, discrimination, personal attacks, intimidation, sexualized language or imagery, publishing private information, deliberate disruption, and any other conduct that would make a reasonable participant feel unsafe or unwelcome.

## Enforcement

Project maintainers may edit, hide, close, or remove comments, issues, discussions, and pull requests that violate this code. They may also restrict participation when necessary to protect the project community.

Report conduct concerns privately through the repository maintainer's GitHub profile:

<https://github.com/Ericwong5021>

Please do not include sensitive security details in a conduct report. Security vulnerabilities belong in [SECURITY.md](SECURITY.md).
