# Plan 4.2：独立降级界面

更新日期：2026-08-12

状态：已并入 [Self-hosted Hub 与 Web UI](PLAN_SELF_HOSTED_WEBUI.md)，本文件仅保留历史设计。

本地降级入口、Browser Host、Web 自动化和远端 Web UI 不再分别实施。后续范围、阶段、验收和回滚统一以新计划为准。

## 目标

在 Codex CDP 或 DOM 注入暂时不可用时，通过本地独立界面继续管理任务、查看历史和完成 Review。

## 启动条件

- 注入兼容维护成本已经通过多个 Codex 版本得到真实数据。
- 用户明确需要更大管理界面或注入故障期间的完整降级入口。
- Runtime API 和宿主适配边界已稳定。

## 范围

- 本地独立界面复用 Runtime、SQLite、领域模型和更新机制。
- 注入界面与独立界面共享组件和数据，不建立第二套业务逻辑。
- 支持 Project、Issue、搜索、状态、Thread 链接、Run 和 Review。
- 明确显示 Codex 与注入状态，不伪造 Thread 跳转成功。
- 仍只监听回环地址，不提供局域网或公网访问。

## 不包含

- 云账号、同步、团队权限、托管服务和移动端。
- 浏览器直接读取 Codex 私有数据库或绕过 Codex 导航。
- 将独立界面改成首发前置条件。

## 验收

- 完全关闭注入后仍能完成任务管理和历史查看。
- 注入界面与独立界面并发编辑时遵守同一版本冲突规则。
- Runtime 重启后界面恢复当前对象和未丢失事件。
- Codex 不可用时 Thread 操作显示明确降级结果。
- 禁用独立界面不影响注入、CLI 和 Runtime。

## 回滚

关闭独立界面路由和静态资源服务，不修改数据库和注入适配器。
