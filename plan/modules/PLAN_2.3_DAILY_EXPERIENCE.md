# Plan 2.3：日常体验打磨

## 目标

根据私测证据优化高频路径，让 Better Codex 从可演示功能变成日常可用工具。

## 优先级

1. 修复阻止安装、启动、关联和返回 Thread 的问题。
2. 修复数据丢失、重复注入、无法关闭和版本不兼容问题。
3. 减少创建、查找、推进和重新进入任务的操作成本。
4. 最后处理视觉一致性与非阻塞体验问题。

## 范围

- 首次使用引导聚焦一个 Project、三张 Issue 和一个 Thread 关联。
- 优化看板状态、搜索、置顶、空状态和错误恢复。
- 明确显示 Runtime、Codex 和兼容层的降级状态。
- 适配 Codex 浅色与深色主题。
- 保持键盘、焦点、滚动和弹层行为不破坏 Codex 原生交互。
- 建立兼容性回归清单和发布前真实桌面验收流程。

## 不包含

- 私测没有证据支持的新功能。
- 新增多 Agent 编排能力、独立 Web UI、云端同步和复杂自定义工作流。
- 没有真实用户证据支持的设置项、状态和自动化入口。
- 仅用于展示但不改善激活或重复使用的动画。

## 验收

- 新用户无需解释即可完成激活路径。
- 常用操作在浅色与深色主题下清晰可读。
- 页面重载、Codex 切换项目和 Runtime 重启后能恢复当前工作。
- 失败状态提供下一步动作，不只显示内部错误码。
- 私测中的所有阻塞级问题均已关闭或有明确的不支持声明。

## 回滚

界面资源版本化发布；体验更新失败时回到上一个完整资源版本，不迁移或删除业务数据。

## 当前进度

- 看板、Agent、调度、通知、归档、浅色与深色主题、文档和常见恢复入口已经可用。
- 当前高优先级体验问题集中在 Session 状态、补充消息、控制权交接、状态解释和安装失败定位。
- 继续按公开 Issue、私测反馈和本地狗粮证据排期，不建立脱离用户反馈的功能清单。
